# 🖼️ Indexation du Dossier d'Images — CV Sié Claude Fofana

Ce dossier contient toutes les images utilisées par le site web de ton CV.

## 📂 Structure des dossiers

```text
public/images/
├── profile/             <-- Dépose ici ta photo de profil (ex: photo-profil.jpg)
│   └── photo-profil.jpg
├── projects/            <-- Images et captures d'écran de tes projets web
│   ├── fsc-shop.jpg
│   ├── bienetre-biovitality.jpg
│   └── dgi-system.jpg
├── affiches/            <-- Vos créations d'affiches publicitaires & graphiques
│   ├── affiche-1.jpg
│   ├── affiche-2.jpg
│   └── affiche-3.jpg
└── logos/               <-- Logos des entreprises / institutions
    ├── dgi-logo.png
    ├── microfinance-logo.png
    └── fsc-logo.png
```

## 🚀 Comment ajouter/remplacer tes images ?

1. Dépose tes fichiers images dans les sous-dossiers correspondants ci-dessus.
2. Formats supportés : `.jpg`, `.png`, `.webp`, `.svg`.
3. Les chemins sont déjà configurés dans l'application (`src/config/images.js`).
4. Si un fichier n'est pas encore présent, le site affiche automatiquement un placeholder élégant.
